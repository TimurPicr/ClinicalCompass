# Согласованные синтетические истории

Набор `realistic-v2` демонстрирует работу программы на вымышленных клинических историях. Это не реальные пациенты и не доказательство клинической эффективности приложения. Все исходные записи, результаты обследований, назначения и документы созданы для демонстрации; AI-сводки не подставляются.

```bash
python -m scripts.seed_demo --cohort realistic-v2
```

Врач: `doctor.realistic-v2@example.com` / `DemoDoctor123!`. Пациенты: `{anna,pavel,maria,andrey}.realistic-v2@example.com` / `DemoPatient123!`. Уже существующие аккаунты и их пароли не меняются. Новый cohort имеет отдельного врача и собственную историю; повторный запуск не добавляет дубликаты.

Каждая карта содержит 21 запись дневника с ежедневными вариациями, три PHQ-9 и три GAD-7, два будущих задания, сообщения и русскоязычный оригинал документа для OCR. Числовое поле `sleep` оценивает качество сна 0–10; продолжительность в часах может встречаться только в явно написанном анамнезе. Значения опросников проверяются по ответам, а не задаются отдельными произвольными суммами.

Назначения и версии в историях вымышлены. У Анны стабильная версия; у Павла и Марии приёмы до и после изменения связаны с соответствующими версиями. Расписание указано по Москве. Последний день наблюдения заканчивается вчера в 20:00 Москвы, поэтому ранний запуск seed не создаёт будущих дневников или приёмов. По мере старения данных организационные правила могут изменить статус; зелёный индикатор не означает доказанное благополучие.

В карте Андрея описан сценарий для обсуждения Авиандра: подтверждённое врачом ГТР у взрослого, результаты обследований, сверка лекарств и анамнеза противопоказаний. Показание и ограничения сверены с [информацией производителя](https://aviandr.ru/patient) 26.10.2026. Наличие показания не делает торговое наименование обязательным выбором. Исходно нет рецепта и записей приёма: врач может создать назначение через обычный интерфейс после оценки. AI не назначает препарат и не меняет дозу.

Для демонстрации откройте дневник, анкеты, карту и назначения одной истории, затем сравните их с AI-сводкой и предупреждениями. У Марии красное правило работает и при `DEMO_RULES=false`: тестовый маркер не используется. Действия «просмотрено» и «подтверждено» не снимают критический сигнал; отклонение с врачебной оценкой сохраняется в истории. AI-пересказ этого же правила не должен оставлять вторую независимую причину красного статуса.

Автоматическая проверка целостности: `python -m pytest tests/test_demo_seed.py -q`. Проверка содержания настоящей модели и пределы такой проверки: [ai-evaluation.md](ai-evaluation.md).
