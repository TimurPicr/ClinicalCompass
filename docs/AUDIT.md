# Аудит до изменения кода

Исходно: чистое рабочее дерево, 8 проходящих тестов. FastAPI имел `/health`, публичные учебные опрос и POST подсчёта, preview учебных рекомендаций. Подсчёт — сумма пяти целочисленных ответов 0–3. Правила — обсуждение сна/концентрации и явно запрошенная срочная связь, источник `demo_rule_v1`.

SQLAlchemy: единственная модель `users` без связи с врачом. Alembic настроен, каталог versions пуст. Записи опроса и рекомендаций не сохранялись. `.env` уже существовал: содержимое не менялось и в отчёт не выводилось.

Frontend: React+TypeScript, одна страница опросника, жёстко заданный API URL, запрос рекомендаций вне обработки ошибок. Авторизации и кабинетов не было. Docker Compose поднимал только PostgreSQL без healthcheck.

Обнаружены отдельные прототипы: корневой `main.py` и `app/database/schemas.py` используют SQLModel/SQLite и не входят в основной backend; `recomendation.py` использует Ollama/Qdrant/PDF, не подключён к маршрутам основного backend. Прототипы сохранены, RAG подключён опциональным адаптером к существующему сервису.

Установленные исходные версии: Python 3.14, FastAPI 0.146.0, SQLAlchemy 2.1.5, Pydantic 2.14.1, Alembic 1.20.0, psycopg 3.3.6, PyJWT 2.15.1, pwdlib 0.3.1, pytest 9.1.1; frontend React 19, TypeScript 6, Vite 8; Node 26 на машине. Ограничения requirements и package-lock учтены; Docker проверяется отдельно на Python 3.12 / Node 24.

Созданы модули auth/patients/alerts/treatments/followup, security/time, clinical models/schemas, workflows/scales/RAG adapter, CLI, миграции, компонентный frontend, тестовые фикстуры и Dockerfiles. Изменены существующие main, API опроса/рекомендаций, экспорт моделей, настройки, frontend, Compose, run.sh и README. Алгоритмы учебного подсчёта и существующий движок правил не переписывались.

Допущения: ведущий врач один, назначение только через принятие email-привязанного приглашения; подтверждённые планы неизменяемы, изменения — новая версия; день самоотчёта — Europe/Moscow; активен только учебный опрос; лекарственные данные вручную проверяет врач; клинический RAG отключён по умолчанию.
